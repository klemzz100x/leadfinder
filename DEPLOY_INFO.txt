VARIABLES D'ENVIRONNEMENT
--------------------------

[OBLIGATOIRE]
DATABASE_URL = URL de connexion Postgres Neon (https://neon.tech, gratuit)
               Format : postgresql://user:password@ep-xxx.neon.tech/dbname?sslmode=require
               À créer sur neon.tech (compte gratuit, aucune carte requise), puis coller
               la "Connection string" dans le dashboard Render → Environment.

[OPTIONNELLES — app fonctionne sans]
PSI_API_KEY          = (PageSpeed Insights — gratuit 25 000 req/jour)
                       https://developers.google.com/speed/docs/insights/v5/get-started

GOOGLE_PLACES_API_KEY = (Google Places API — nécessite une CB)
                        Google Cloud Console

BRAVE_API_KEY        = (Brave Search — gratuit 2 000 req/mois)
                       https://api.search.brave.com/
